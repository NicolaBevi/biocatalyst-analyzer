# BioCatalyst Analyzer

🚧 **In sviluppo** — scheletro del progetto (Fase 0/10). Descrizione completa,
architettura, screenshot ed esempi d'uso arriveranno a fine sviluppo.

Report di due diligence multi-agente su aziende biotech/pharma quotate su
NASDAQ/NYSE, orientati all'analisi di catalizzatori clinici e regolatori a
breve termine.

## Setup rapido

```bash
cp .env.example .env
# compila .env con le tue API key

uv sync
uv run pytest
uv run biocatalyst version
```

## Disclaimer

Questo strumento produce contenuto **puramente informativo**, generato in
parte da modelli linguistici e da dati di fonti pubbliche. Non costituisce in
alcun modo consulenza finanziaria, raccomandazione di investimento o invito a
investire. Verifica sempre i dati con le fonti primarie prima di qualsiasi
decisione.
